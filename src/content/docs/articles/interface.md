The studio is three regions: a device rail, the viewport, and the inspector.

## The device rail

On the left, grouped by kind. Selecting a device reframes the camera and resizes the plinth to suit it, so you never arrive at a device that is cropped or floating.

Press **[** to hide it when you want more room.

## The viewport

The 3D scene. Navigation is the same as most 3D editors:

| Input | Action |
| --- | --- |
| Drag | Orbit around the product |
| Right-drag or middle-drag | Pan |
| Scroll | Zoom |
| **F** | Frame the current device |

There is also a **Fly** mode in the Camera tab, which releases the camera from orbiting a fixed point — useful for getting inside or behind a scene.

## The inspector

On the right, split into tabs. Press **]** to hide it.

| Tab | What lives there |
| --- | --- |
| **Device** | Colour, materials, which physical details are shown, orientation |
| **Screen** | Your screenshot, how it fits, overlays, window chrome |
| **Scene** | Backdrop, plinth, shadow, exposure and post-processing |
| **Camera** | Angle presets, field of view, navigation settings |
| **Light** | Lighting rigs, individual lights, the room, environment maps |
| **Animate** | Motion clips and playback |
| **Export** | Image and video output |
| **Presets** | Premade looks, and saving your own |

## Everything is a live control

There is no apply button. Every control writes straight to the scene, so you can drag a slider and watch the render change.

Changes are not saved automatically — if you land on a look you want to keep, save it as a preset. See [Presets and sharing](/docs/presets).
