Keyboard shortcuts work anywhere in the studio, except while you are typing in a text field.

## Studio

| Key | Action |
| --- | --- |
| **F** | Frame the current device |
| **Space** | Play or pause the animation |
| **[** | Show or hide the device rail |
| **]** | Show or hide the inspector |

## Viewport navigation

| Input | Orbit mode | Fly mode |
| --- | --- | --- |
| Drag | Orbit | Look |
| Right-drag / middle-drag | Pan | — |
| Scroll | Zoom | — |
| **W A S D** | — | Move |
| **R** / **F** | — | Up / down |

> [!NOTE]
> Modifier combinations are deliberately left alone, so your browser's own shortcuts keep working.
